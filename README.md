# TNG eWallet Simulator

A simple C++ program inspired by Touch 'n Go (TNG).

## Innovation model
Christensen's Disruptive Innovation.
TNG disrupted cash payments - first at highway tolls, then at shops with QR Scan & Pay.

## Inputs
- Menu choice (1-5)
- Reload amount (RM)
- Toll plaza choice
- Shop name and payment amount (RM)

## Outputs
- Current balance
- Payment / reload confirmation
- Error messages (invalid amount, insufficient balance)
